# Task: v0.23.1 Scope-Trim Audit (Start at `6be3c358...`)

**Status:** In Progress (Chunk 1 + Chunk 2 complete)  
**Created:** 2026-03-04  
**Objective:** Build a lean `v0.23.1` path from `v0.23.0` that keeps:

1. robust sync workflow,
2. `get-posts-by-ids` batching,
3. workflow-attached enrichment policies with CLI override,
4. minimal global config.

And trims/de-scopes:

1. multi-lane dispatch/runtime orchestration,
2. rollout scaffolding/toggles that are not required for normal operation,
3. queue/operator command surface that creates UX bloat.

---

## Desired Target Shape (Lean)

1. `sync` remains the primary orchestrator (fetch/store/delete, media/enrich children).
2. Enrichment policy comes from:
   - workflow default profile (in code/registry),
   - optional CLI `--policy` override.
3. Batch enrich module supports two behaviors:
   - `fire-now` (immediate),
   - `fire-when-full` (deferred/buffered).
4. Keep env vars only for true global runtime concerns (credentials, infra paths, coarse global limits).

---

## Audit Rubric

1. **Keep**: directly supports lean target with low conceptual overhead.
2. **Refactor**: useful core exists, but current shape is too coupled/noisy.
3. **Defer**: valuable later, but not needed for `v0.23.1` target.
4. **Drop**: misaligned with target and should not be carried forward.
